# Rock Paper Scissors (Python Console Game)

## 1. Project Title
Rock Paper Scissors (Python Console Game)

## 2. Description of the Game
This is a beginner-friendly Python game where you play **Rock, Paper, Scissors** against the computer in the terminal.

## 3. How the Game Works
1. You type your choice: `rock`, `paper`, or `scissors`.
2. The computer randomly chooses one option.
3. The game compares both choices.
4. You see the result: **win**, **lose**, or **tie**.
5. You can choose to play another round.

The game also checks invalid input and asks you to enter a correct value.

## 4. Technologies Used
- Python 3
- Built-in `random` module

## 5. How to Run the Program
1. Make sure Python 3 is installed.
2. Open a terminal in this project folder.
3. Run:
   ```bash
   python3 rock_paper_scissors.py
   ```
4. Follow the on-screen prompts.
